```
※ 개인이 만든 앱입니다. 정부·지자체·택시회사와 제휴하거나 승인받은 서비스가 아니며, 어떤 기관도 대표하지 않습니다.

📞 자주 거는 번호, 큰 버튼 한 번으로

큰글씨 한번콜은 휴대폰 글씨가 작아 불편한 분을 위해 만든 큰 글씨·음성안내 전화 도우미입니다. 동네 콜택시처럼 자주 거는 번호를 한 번만 저장해 두면, 다음부터는 큰 버튼 하나로 바로 전화가 걸립니다.

■ 주요 기능
1. 한 번에 전화 — 직접 저장한 콜택시 번호로 큰 버튼 한 번에 전화 연결
2. 보호자 전화 — 가족 번호를 저장해 한 번에 전화
3. 내 위치 문자보내기 — 현재 위치(지도 링크 포함)를 보호자에게 문자로 전송
4. 자주 가는 곳 — 병원·장터 등 목적지를 저장하고 음성으로 들려주기 (기사님께 보여주기 좋아요)
5. 음성 안내 — 버튼과 안내를 음성으로 읽어 주어 눈이 어두운 분도 안심
6. 번호 문의처 안내 — 번호를 모를 때 지역 민원 상담전화로 문의하도록 안내

■ 이런 분께
• 작은 글씨와 복잡한 앱이 불편한 어르신
• 떨어져 사는 부모님 휴대폰에 호출 버튼을 설정해 드리고 싶은 가족
• 큰 글씨·음성안내가 필요한 분

■ 개인정보·오프라인
• 입력한 정보(전화번호·보호자·자주 가는 곳)는 내 휴대폰에만 저장되며 외부 서버로 보내지 않습니다.
• 위치정보는 "내 위치 문자보내기"를 누를 때만 잠깐 쓰이고 저장되지 않습니다.
• 처음 실행한 뒤에는 인터넷 없이도 작동합니다.
• 광고·추적·회원가입이 없습니다.

■ 알아두세요
이 앱은 사용자가 저장한 번호로 전화를 걸어 주는 도구일 뿐, 택시를 직접 배차하거나 요금을 정하지 않습니다. 콜택시 번호와 이용 조건은 지역마다 다르니 거주지 시·군청이나 읍·면·동 주민센터에 확인한 뒤 저장해 사용하세요.
```
