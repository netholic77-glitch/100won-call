# Play Console — 콘텐츠 등급(Content Rating) 설문 답변 가이드

Play Console → **앱 콘텐츠 → 콘텐츠 등급** 에서 IARC 설문을 진행합니다.
백원콜은 생활 편의 도구이므로 거의 모든 항목에 "아니요"입니다.

## 카테고리 선택
- **앱 카테고리**: **유틸리티 / 생산성 / 기타 (Utility, Productivity, Communication, or Other)**

## 설문 답변

| 질문 | 답변 |
|---|---|
| 폭력적 행위가 포함되어 있나요? | 아니요 |
| 성적인 콘텐츠가 포함되어 있나요? | 아니요 |
| 욕설이 포함되어 있나요? | 아니요 |
| 통제 약물의 사용을 묘사하나요? | 아니요 |
| 도박이 가능한가요? | 아니요 |
| 사용자가 다른 사용자와 상호작용하나요? | 아니요 (저장은 본인만, 사용자 간 공유 없음) |
| 사용자가 정확한 위치를 공유하나요? | 아니요 (위치는 사용자가 직접 보호자에게 문자로 보낼 때만 사용, 앱이 공유하지 않음) |
| 앱이 사용자의 개인정보를 수집하나요? | 아니요 |
| 디지털 구매(인앱 결제)가 가능한가요? | 아니요 |
| 앱이 사회·정치적으로 민감한 주제를 다루나요? | 아니요 |
| 앱에 광고가 표시되나요? | 아니요 |

> ※ "정확한 위치 공유" 항목: 앱이 위치를 다른 사용자에게 자동 공유하는 기능이 아니라, 사용자가 자신이 지정한 보호자에게 직접 문자를 보내는 보조 기능이므로 "아니요"가 적절합니다. 다만 심사기관이 다르게 볼 여지가 있으면 "예"로 답해도 등급에 큰 영향은 없습니다.

## 예상 등급

| 지역 | 등급 |
|---|---|
| 대한민국 (게임물관리위원회) | **전체이용가** |
| 미국 (ESRB) | Everyone |
| 유럽 (PEGI) | PEGI 3 |
| 호주 (ACB) | G (General) |

## 설문 진행 팁

- 설문을 저장하면 IARC 인증서 번호가 발급되어 자동으로 등록정보에 반영됩니다.
- 향후 사용자 간 공유·광고 기능을 추가하면 반드시 설문을 다시 진행하세요.
