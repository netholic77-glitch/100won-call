# Play Console — 데이터 보안(Data Safety) 양식 답변 가이드

Play Console → **앱 콘텐츠 → 데이터 보안** 에서 아래대로 입력하세요.

## ① "앱이 사용자 데이터를 수집하거나 공유하나요?"

**답변: 아니요 (No)**

백원콜은 사용자가 저장한 모든 정보(택시 콜센터 번호, 보호자 이름·전화번호, 자주 가는 곳, 지역 선택)를 **기기 내부 저장소(localStorage)** 에만 저장하며, 개발자나 제3자 서버로 전송하지 않습니다. 광고·분석·트래킹 SDK도 포함하지 않습니다.

→ "아니요" 선택 시 이후 세부 질문은 자동으로 건너뜁니다.

## ⚠ 위치정보에 대한 정확한 설명 (중요)

이 앱에는 "내 위치 문자보내기" 기능이 있습니다. 다만 **데이터 보안 양식 기준으로는 "수집(collect)"에 해당하지 않습니다.** 그 이유:

- 위치(위도·경도)는 사용자가 버튼을 누른 그 순간에만 기기에서 일시적으로 읽습니다.
- 앱이 이를 **저장하거나 개발자 서버로 전송하지 않습니다.**
- 위치는 사용자의 기본 문자(SMS) 앱에 **문자 본문으로 전달**되며, 실제 전송은 사용자가 직접 전송 버튼을 눌러야 이루어집니다(사용자 주도 행위).

Google 데이터 보안 정책상 "기기에서만 처리되고 전송되지 않는 데이터", "사용자가 직접 보내는 행위"는 수집·공유 신고 대상이 아닙니다. 따라서 **"아니요"** 가 정확합니다.

> 만약 심사에서 위치 관련 질의가 오면 위 내용을 그대로 답변하세요.

## ② "전송 중 데이터가 암호화되나요?"

**해당 없음** (앱이 서버로 데이터를 전송하지 않음)

## ③ "사용자가 데이터 삭제를 요청할 수 있나요?"

**해당 없음** (서버 측 저장 없음). 사용자는 앱 데이터 삭제 또는 앱 제거로 모든 정보를 즉시 폐기 가능.

---

## 데이터 종류별 요약표

| 카테고리 | 수집 | 비고 |
|---|---|---|
| 위치 | 미수집 | 문자 작성 시에만 기기 내 일시 사용, 전송·저장 안 함 |
| 개인정보(이름·전화번호) | 미수집 | 보호자 정보는 기기 내부에만 저장 |
| 연락처 | 미수집 | 주소록 접근 안 함 (사용자가 직접 입력) |
| 금융 정보 | 미수집 | — |
| 앱 활동·식별자 | 미수집 | 분석 SDK 없음 |

## Play Console 미리보기 확인

답변 입력 후 다음 문구가 보이면 정상:

> "이 앱은 사용자 데이터를 수집하거나 공유하지 않습니다."
