# 스크린샷 캡처 가이드

Play Console은 휴대전화 스크린샷을 **최소 2장, 권장 4~8장** 요구합니다.

## 캡처 방법 (PC Chrome)

1. PC Chrome으로 배포된 Netlify URL 접속 (예: https://baekwon-call.netlify.app)
2. `F12` (개발자 도구) → `Ctrl+Shift+M` (모바일 토글) → 기기를 **Pixel 7 Pro** 또는 **1080×1920** 으로 선택
3. 각 화면에서 우측 ⋮ → **"Capture screenshot"**
4. 권장 사이즈: 1080×1920 (세로). 최소 320px, 최대 3840px

## 권장 6컷 구성

| # | 화면 | 캡처 포인트 |
|---|---|---|
| 1 | 인트로 | 🚕 백원콜 로고 + "시작하기" 버튼 |
| 2 | 메인 — 택시 부르기 | 큰 초록 "택시 부르기" 버튼 + 보호자/위치 버튼 |
| 3 | 내 택시 번호 저장 | 지역 선택(광역→시군) + 운영 안내 + 번호 입력 |
| 4 | 보호자 | 보호자 저장 + "내 위치 문자보내기" |
| 5 | 자주 가는 곳 | 목적지 목록 + 🔊읽기 버튼 |
| 6 | 음성 안내·안내전화 | 🔊음성 토글 + 120/110 안내 |

## 캡처 시 팁

- 1번(인트로)과 2번(큰 버튼) 두 장이 가장 중요합니다. 스토어 목록에서 어르신용 큰 버튼이 한눈에 보이도록.
- 데모용으로 택시 번호·보호자에 예시값(예: 우리면 행복택시 / 큰딸)을 넣어 캡처하면 이해가 쉽습니다.
- 실제 개인 전화번호는 가리거나 예시 번호(0312345678 등)를 사용하세요.

## 아이콘·그래픽 (이미 생성됨)

| 파일 | 용도 | 규격 |
|---|---|---|
| `icon_512.png` | 앱 아이콘 | 512×512 |
| `feature_graphic_1024x500.png` | 피처 그래픽 | 1024×500 |

수정이 필요하면 `generate_pngs.py`를 고쳐 다시 실행하세요 (`python generate_pngs.py`).
