# 🚕 백원콜 (baekwon-call)

농어촌 **100원·행복택시**를 어르신도 쉽게 전화로 부를 수 있게 돕는 고령자 친화 호출 도우미.
설치형 PWA → Google Play Store 배포(AAB) 구조. **100% 기기 내부 동작, 외부 서버 없음.**

## 무엇을 하나
공공형 택시(행복택시·희망택시·마중택시·100원택시)는 대부분 전용 앱 없이 **콜센터 전화 예약**으로 운영됩니다. 백원콜은 매번 번호를 찾기 어려운 어르신을 위해:

- **택시 부르기** — 우리 동네 콜센터 번호를 한 번 저장 → 큰 버튼 한 번으로 전화 연결
- **보호자 전화 / 내 위치 문자보내기** — 가족에게 한 번에 전화하거나 현재 위치(지도 링크)를 문자로 전송
- **자주 가는 곳** — 병원·면사무소·장터를 저장하고 음성으로 들려주기 (기사님께 보여주기 좋음)
- **음성 안내** — 버튼·안내를 읽어줌
- **정부 안내전화** — 번호를 모를 때 120(시군청)·110(정부민원) 바로 연결

## 기술
- 순수 정적 PWA (HTML/CSS/Vanilla JS), 빌드 도구 없음
- 저장: `localStorage` / 전화·문자: `tel:` `sms:` / 위치: `navigator.geolocation` / 음성: Web Speech API
- 오프라인: Service Worker 캐싱
- 전국 229개 시·군 행복택시 운영 안내 디렉터리(`www/data/regions.json`)

## 로컬 실행
```bash
npm run serve   # http://localhost:8531
```

## 배포
`HOW_TO_PUBLISH.md` 참조 — Netlify Drop → PWABuilder AAB → Play Console.

## 한계 (정직한 고지)
실제 택시를 **자동 배차하지 않습니다.** 각 지자체 콜센터/배차 시스템은 공개 API가 없어, 전화 연결까지를 돕는 도우미로 설계했습니다. 콜센터 번호는 지자체마다 다르고 매년 바뀌므로 임의 번호를 넣지 않고 사용자가 직접 저장하도록 했습니다.
